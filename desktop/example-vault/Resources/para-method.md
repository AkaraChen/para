# The PARA Method

Reference notes. No owner, no deadline.

| Bucket | Question |
| --- | --- |
| Project | Finish line + outcome? |
| Area | Standard to keep? |
| Resource | Topic to keep? |
| Archive | Inactive but searchable? |

Never invent a fifth top-level folder.
